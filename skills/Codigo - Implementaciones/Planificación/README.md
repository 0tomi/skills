# Planificación

Skills para decidir qué y cómo implementar antes de tocar código.

| Skill | Qué hace |
|---|---|
| `prototype-html` | Prototipa los cambios propuestos (o explica un tema) en un HTML interactivo para tantearlos antes de planificar. |
| `planificar` | Arma el plan de implementación: enfoque, estructura, riesgos, tradeoffs y orden de trabajo. |

Flujo típico: `prototype-html` → `planificar` → `orquestar-planes` (en [Agentes/Delegación](../../Agentes/Delegación/)).
