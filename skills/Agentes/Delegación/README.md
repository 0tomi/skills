# Delegación

Skills para repartir trabajo entre subagentes y supervisarlo.

| Skill | Qué hace |
|---|---|
| `orquestar-planes` | Ejecuta un plan por fases delegando en subagentes, valida cada entrega contra el plan y el diff, y commitea cada fase validada. |
| `codex-delegation` | Protocolo para que Codex elija qué modelo y esfuerzo usar en cada subagente (Terra, Sol o Gemini). |
